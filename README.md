# Развесели улыбашек 🥊

Игра: бьёшь грустные лица боксёрской перчаткой, после трёх ударов они радуются.
Счётчик «удары за всё время» общий для всех игроков и хранится в Netlify Blobs.

## Что где лежит

- `index.html` — сама игра
- `faces/` — фотографии лиц (квадратные, 200×200)
- `netlify/functions/punches.mjs` — сервер для общего счёта (`/api/punches`)
- `netlify.toml`, `package.json` — настройки для Netlify

## Как выложить

1. Создай репозиторий на GitHub и загрузи туда все эти файлы (вместе с папками).
2. На netlify.com: **Add new site → Import an existing project → GitHub**, выбери репозиторий.
3. Поля сборки оставь как есть: Build command пустая, Publish directory `.` (всё уже указано в `netlify.toml`).
4. Нажми **Deploy**. Через минуту игра будет доступна по ссылке Netlify.

Netlify Blobs включается сам, ничего настраивать не нужно.

## Как добавить или убрать человека

- Добавить: положи квадратное фото в `faces/`, например `faces/ivan.jpg`, и добавь строку
  в список `FACES` в `index.html`: `{ id: 'ivan', src: 'faces/ivan.jpg' },`
- Убрать: удали его строку из `FACES` (и фото из `faces/`). Его старые удары просто перестанут показываться.

## Заметки

- Если открыть `index.html` просто как файл, игра работает, но счёт хранится только в этом браузере.
- Каждый браузер считается отдельным игроком, его удары хранятся отдельно, а в рейтинге показывается сумма.
